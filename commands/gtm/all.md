Run the gtm skill's full review with every sub-command on the current project.

Invoke the `gtm` skill and follow it with this input:

`all $ARGUMENTS`

That is `/gtm on` with `--all`: validate, brief, competitors, personas, interviews, mvp, pricing, plan, metrics, fundraise and deck, plus feature when an addition is named in the input.
