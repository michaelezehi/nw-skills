# Phase 4 recipe — backlink outreach list

Researched manual outreach that complements the Optics Link Network (automated relevance-matched exchanges — see `link-network.md`). No paid-link suggestions, no bulk schemes.

## Research (WebSearch, per cluster + brand niche)

| Target type | Query patterns |
|---|---|
| Resource pages | `intitle:resources <niche>` · `"useful links" <niche>` · `<niche> "resources for"` |
| Guest-post blogs | `<niche> "write for us"` · `<niche> "guest post guidelines"` |
| Directories | `<niche> directory` · `best <category> tools list` |
| Listicle inclusion | `best <category> <year>` · `<competitor> alternatives` (authors already covering competitors) |
| Newsletters/communities | `<niche> newsletter` · `<niche> community` |

For each candidate, WebFetch enough to confirm: real site, relevant audience, plausible contact route (contact page, submission form, author byline). Skip obvious link farms (thin content, unrelated outbound links).

## Output

Fill `templates/BACKLINK-OUTREACH.template.md` with ≥15 vetted targets. For each: why it's relevant (one line, specific) and which asset to pitch — usually a pillar article or the product itself. Write the 3 pitch templates in the brand voice from STRATEGY.md, ≤120 words each, no hype adjectives.

Re-runs append new targets (dedupe by domain) and never touch rows the user has moved past `todo`.
