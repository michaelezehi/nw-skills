# Pitfalls: every bug the reference build hit, as rules

| # | Symptom | Cause | Rule |
|---|---|---|---|
| 1 | "Beat 4 of 18" on a founder screen confused the viewer | one script across every role, script jargon in the UI | one story per role; "Step n of N"; no script words |
| 2 | Blank screen while the story switched persona or page | the frame paused with nothing in it; only user-picked switches showed a loader | every switch runs under `withSwitch`, and the loader always renders |
| 3 | The reader's picture spilled over the title | art sized at `72%` grows with the panel's width, not its 150px height | art at a fixed pixel size inside an `overflow-hidden` box |
| 4 | "Show me how" always rang Home | the role home (`/app`) is a parent of every route, so the longest-parent fallback found it | a one-segment home matches only itself; `REACHED_THROUGH` maps tab screens to their menu item; no match, no button |
| 5 | The spotlight never clicked, or clicked late | its timer effect depended on the `onDone` prop, so every parent render restarted it | `useEffectEvent` for the click, effect keyed on the target only |
| 6 | Back made the story jump forward | closing the reader resolved `untilExplained`, and the loop advanced before it saw the stop flag | in `haltLoop`, cancel the wait BEFORE clearing the explanation |
| 7 | The loop never started in development | StrictMode unmount set the alive flag false and the remount never set it back | set `aliveRef.current = true` in the mount effect, every mount |
| 8 | The countdown ran out while the next screen was still loading | it ticked through the switch | the countdown holds while `pending > 0`, while paused, and while the spotlight shows |
| 9 | Two open tabs played the story at double speed | both ran the loop | `expectedIndex` idempotency plus a per-tab driver lease (director tier) |
| 10 | Prompt cards hid under the reader | both pinned top right | the prompt stack moves left by the reader width + 32px while it is open |
| 11 | Switching to another role's story left the last story's data behind | the run row was reused | starting a different story undoes the previous one's writes first |
| 12 | Arrow keys hijacked the page's own arrow navigation | a global listener | listen only while a story is under way; skip editable targets and modifiers; say so in the report |
| 13 | A restart test passed with dangling references | it compared row counts | compare content with ids stripped, and check every id resolves |
| 14 | Effects emailed a persona | a shared helper scheduled a send | the recording ctx swallows the scheduler; persona emails are on an unroutable domain that throws |
| 15 | A step that only changes `?tab=` stayed on the old tab | the loop compared paths without the query and returned early | same path, different query: `router.push` the step route in place, no loader |
| 16 | The last step never opened its reader while playing | the loop broke on any status but `playing`, and the last advance returns `done` | on `done`, open the last step's reader, then stop |
| 17 | "Show me how" found nothing for menu destinations | dropdown links render into a portal only while the menu is open | mark the trigger and its menu container with `data-walkthrough-menu`; ring and click the trigger, wait for the menu, then ring the link |
| 18 | Homes that are not one segment (`/{org}/{company}/overview`, `/me/overview`) caught every route | the one-segment home rule assumes flat homes | hosts with scoped homes pass an explicit homes list that matches only itself |
| 19 | The spotlight ring hid under an open dropdown | the menu's own z (9999+) is above the ring's 120 | lift the ring above the menu only while it rings a link inside a marked menu |
| 20 | The reader stayed open for good with sound on | it waited for the clip's `ended`, and a stalled download fires neither `ended` nor `error` | the reader gives up after `CLIP_CEILING_MS`; the Explain-off hold after `LEAD_CEILING_MS` |
| 21 | Pausing the story stopped the voice, but the card closed mid sentence | the reader's countdown ignored the run's pause | with a clip under way, a paused run holds the countdown too; muted timing is unchanged |
| 22 | A late `ended` from a cut clip moved the story on | the listener did not know which clip ended | every `play()` returns a token; `ended` and `error` from a stale token are dropped |
| 23 | Every persona switch cut the lead clip | the switch remounts the layout, and the hook stopped on unmount | stop on unmount only after `UNMOUNT_GRACE_MS`; the player and narration state live outside the component |
| 24 | Narration stayed silent on iOS Safari | the unlock and the clip used different elements, or `playsinline` was missing | one shared element, unlocked inside the click, with the property and the attribute |
| 25 | The sound button announced "Turn sound off, pressed" | its name changed with its state while `aria-pressed` also changed | a fixed name ("Sound") and `aria-pressed` for on or off |
| 26 | The step talked about a tab but the screen never moved to it | the route pointed at the page, and nothing clicked the tab | a `focus` spec with `click: true` on the tab: the pass lights it, clicks it, then the query in the route is only the fallback |
| 27 | A step opened a full-screen payroll wizard and started a new run | its focus clicked a button that creates something | only tabs get `click`. Anything that runs, sends, saves, publishes, records, generates, charges or opens a pop-up is lit, never clicked |
| 28 | A full-screen overlay covered the whole tour | the step route carried the param that opens it full screen (`?companion=full`) | never route to a full-screen or modal param; use the corner or inline version, or light the button that opens it |
| 29 | The ring lit an empty hole | the control was still fading in (opacity 0 on it or a parent) | skip anything with opacity under 0.01 and keep polling until `FOCUS_FIND_MS` |
| 30 | Three rings at once and the viewer did not know where to look | the pass lit every spec of the step together | `primaryFocus`: light only what the step clicks, one stage at a time, or its first control when it clicks nothing |
| 31 | A stat's ring hugged the tiny pill round its label | `areaOf` stopped at the first rounded box, which was the pill | climb past rounded boxes under 48px tall to the card or stat cell, and stop below a row wider than 70% of the screen. A zero height is unmeasured (jsdom), not small |
| 32 | The Companion stayed open on every page after its step | a step opened it with a query (`?companion=1`); the next step on the same page had no query, so the loop left the URL alone, and ending the tour touched nothing | name the opener params (`OPENER_PARAMS`). The next step takes off any it does not set itself, keeping the tab; the tour's unmount takes them off too |
| 33 | The reader sat on top of the card it was explaining | the reader was pinned to the end side, full height, whatever the step was about | `useReaderPlacement`: end, then start, then a short bottom panel, the first that covers none of the step's focus targets; re-measure each second; glide with `layout` |
| 34 | A Saudi-only story (Nitaqat) showed to every company | stories were gated by the viewer's role only | gate on the company's own setup (`regions` / `notRegions` from the company record) and on enabled modules; drop a story left with fewer than 3 steps |
| 35 | The story picker showed raw keys (`walkthrough.stories.x.label`) in other languages | labels were added to the English catalog only | every label key in every locale before shipping; compose and diff the bundles' leaf keys, since compose can pass while a locale is short |
| 36 | Arrow keys and M moved the story while the picker list was open | the key hook only skipped inputs | also skip `combobox`, `listbox`, `option` and `menu` roles |
| 37 | A locale file turned invalid JSON after the translation run reported done | the run started each locale with `&`, so late writes landed after it exited, and the translator turned the German and Chinese curly quotes into bare `"` inside values | translate in the foreground or `wait` for every child; parse every fragment before composing; escape stray quotes inside values; compose and refresh any parity baseline only after all writers exit |
| 38 | Two clip runs for one app raced on the manifest | English and Arabic generation ran at the same time | generate one locale at a time per app; a `--dry-run` across all locales must print `0 to generate` at the end |
| 39 | A formatter turned `\u2014` in a dash-check regex into a literal dash | the formatter normalised escapes in source | keep dash checks in a script or test that the formatter does not rewrite, and grep the result |
| 40 | A step about a tab lit nothing, and the tab changed only through the URL fallback | the host's tab strip rendered plain buttons with no `role="tab"`, and a tab spec searched only `[role="tab"]` | a tab spec tries `[role="tab"]`, then ONE button with the name (the first beside other buttons), never a link; on a host with no catalog, a test greps the source for every focus label |

When a new bug turns up in a host, add a row here (and to nw-skills).
